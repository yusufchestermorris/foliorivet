# 0.1.0a1 preview changelog

Unreleased, 6 November 2026.

- Native synchronous Python inspection, preflight and DOCX generation.
- Shared Rust/CLI scalar, row, inline-picture, whole-block repetition and optional-block operations.
- Exact target diagnostics, bounded input validation and refusal to overwrite output paths.
- Bounded style/table/theme preservation repairs and heading/table pagination repair.
- Independent FolioRivet README and CLI identity; source ArtCraft logo/mark files archived privately.
- Windows CPython 3.12 wheel and Linux manylinux_2_35 candidate built locally.

Experimental scope: no universal OOXML preservation, desktop release, nested
variable blocks, reference-bearing repeat prototypes, abi3 or Python versions
other than 3.12. Final release clearance and separate-machine acceptance pending.
