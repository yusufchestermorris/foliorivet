# Report a preview issue

Use a minimal original synthetic template/input. Include FolioRivet artifact
hash/version, OS/architecture, Python version, exact command, expected result,
actual result and complete error. Record fonts and Word version for layout issues.
Remove private data, user paths, document properties and proprietary images.
State fixture authorship and redistribution permission. Do not upload a private
report or Word-produced review copy as a regression fixture.

A fix should include a failing regression, focused Rust tests, installed native
Python/CLI checks and renewed Word evidence where output changes. Preserve
upstream licenses and notices. Public issue destination is not configured yet.
