# Installed Python regression

After installing a built wheel into a fresh CPython 3.12 environment, run:

```text
python -I bindings/python/tests/installed_smoke.py REPO NEW_RESULTS MATCHING_CLI
```

This delegates to the public three-example native/CLI regression and uses no
private fixtures. Rust workspace template tests cover detailed operations and
hostile inputs. Historical stage-specific qualification and Word automation
harnesses are ignored local records, not prerequisites for contributors.
