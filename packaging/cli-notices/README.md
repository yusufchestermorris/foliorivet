# CLI-only dependency notice supplement

CLI bundles include the shared Windows/Linux dependency notice set from
bindings/python/python/foliorivet/licenses/dependencies plus these five CLI-only
package entries. The exact texts and hashes come from the recorded CLI dependency
inventory; they are not regenerated guesses or a binary SBOM. Keep required
notices when changing packaging or dependency versions. Inventories and source
hashes are preserved. Python bindings do not depend on this supplement at runtime.
